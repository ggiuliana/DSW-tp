# Tracking de Features, Bugs e Issues

Para el seguimiento de tareas, asignación de responsabilidades y tracking de bugs, el equipo utiliza **los issues de GitHub**.

## Enlace al Tablero Principal

**[Link Aquí ](https://github.com/ggiuliana/DSW-tp/issues)**

## 🛠 Metodología de Trabajo

Hemos organizado los issue con las siguientes etiquetas:

1. **Enchacement:** Nueva característica o requerimiento.
2. **Documentation:** Mejoras de la documentación
4. **UI/UX:** Cambios exclusivos de la interface de usuario.
5. **Bugs:** Errores encontrados durante el uso de la aplicación, detallando el comportamiento esperado vs. el comportamiento actual.
6. **Review:** Tareas finalizadas que requieren revisión.
